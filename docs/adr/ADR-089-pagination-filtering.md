# ADR-089: 상품 목록 조회 시 페이지 나누기와 필터링을 어떻게 구현할까요?

- 상태: 승인됨
- 날짜: 2026-10-11
- 요청: 실제 운영 가능한 쇼핑몰을 만들어주세요.

## 결정
**Offset/Limit 페이지네이션** — 전통적인 페이지 번호 기반

근거(장점):
- 구현 간단
- 사용자 친화적

## 검토한 대안
- Cursor 기반 페이지네이션 (커서 위치 기반 다음 데이터 조회) → 구현 복잡도 이유로 제외
- 무한 스크롤 (스크롤 시 자동으로 데이터 로드) → 서버 부하 증가 가능 이유로 제외

## 영향
사용자 경험과 서버 성능 결정 · 감수: 대용량 데이터 성능 저하
