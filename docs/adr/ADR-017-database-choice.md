# ADR-017: 데이터베이스는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-03
- 요청: 실제 운영 가능한 쇼핑몰 하나 만들어줘

## 결정
**PostgreSQL** — 관계형 데이터베이스

근거(장점):
- ACID 보장
- 복잡한 쿼리 강력
- 확장성 우수

## 검토한 대안
- MongoDB (NoSQL 문서 데이터베이스) → 트랜잭션 제한, 데이터 중복 가능성 이유로 제외
- SQLite (경량 파일 기반 DB) → 동시성 약함, 대규모 확장 부적합 이유로 제외

## 영향
데이터 관리 방식 및 쿼리 성능 결정 · 감수: 설정 복잡도, 단순 프로젝트에는 과도
