# ADR-086: 프론트엔드 프레임워크는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-11
- 요청: 실제 운영 가능한 쇼핑몰을 만들어주세요.

## 결정
**React** — 컴포넌트 기반, 큰 생태계, 상태관리 자유도 높음

근거(장점):
- 풍부한 라이브러리
- 커뮤니티 활발

## 검토한 대안
- Vue.js (점진적 프레임워크, 낮은 진입장벽, 통합 솔루션) → 커뮤니티 규모 작음 이유로 제외
- Next.js (React 기반 풀스택, SSR/SSG 지원, API 라우트 내장) → 복잡도 증가 이유로 제외

## 영향
UI 개발 방식과 사용자 경험 구현 방식 결정 · 감수: 보일러플레이트 코드 많음
