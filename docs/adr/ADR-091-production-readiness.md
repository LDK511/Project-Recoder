# ADR-091: 실제 운영 가능한 수준으로 쇼핑몰을 개선합니다

- 상태: 승인됨
- 날짜: 2026-10-12
- 요청: 실제 운영 중인 쇼핑몰의 모범 사례를 참고해 운영 가능한 수준으로 개선해 주세요.

## 배경 (개선 전 상태)
- 백엔드가 **빌드되지 않았습니다** (tsconfig `module`/`moduleResolution` 불일치, 타입 오류 40여 개).
- DB 스키마를 적용하는 코드가 없어 빈 DB 에서 서버가 시작되지 않았습니다 (`db:init` 이 가리키는 파일 없음).
- 프런트엔드 CSS 파일이 모두 비어 있어 대부분의 화면이 스타일 없이 표시되었습니다.
- 서버 오류 형식(`{error:{...}}`)과 화면이 기대하는 형식(문자열)이 달라 오류가 나면 화면이 깨졌습니다.
- 배송지 입력이 없어 실제 배송이 불가능했고, 결제대기 주문이 재고를 영구히 붙잡았습니다.
- 관리자 '주문 관리' 화면이 관리자 API 가 아닌 본인 주문 API 를 호출했습니다.

## 결정
기술 구성(React · Express · PostgreSQL · Stripe, 오프셋 페이지네이션, S3)은 기존 ADR 그대로 유지하고,
국내 운영 쇼핑몰(쿠팡·무신사·29CM 등)의 공통 흐름과 공개된 UX 연구(Baymard Institute)를 기준으로 기능과 화면을 보강합니다.
`backend/src/payments/stripe.ts`(플랫폼 관리 파일)는 수정하지 않고 그대로 사용합니다.

### 주요 변경
- **결제 안전성**: 웹훅 이벤트 기록과 주문 상태 변경을 한 트랜잭션으로 처리, 금액·통화 검증, 취소된 주문에 들어온 결제 자동 환불, 결제 멱등키 `order-<id>-<주문키>`.
- **주문**: 주문번호(YYYYMMDD+일련번호), 배송지·배송비 저장, 주문 시점 상품명/이미지 스냅샷, 상태 이력(감사 로그), 고객 취소(결제완료까지, 자동 환불), 관리자 송장 등록.
- **재고**: 원자적 차감(`stock >= qty` 조건부 UPDATE), 데드락 방지 정렬 잠금, 취소·만료 시 멱등 복구.
- **상품**: 카테고리, 정가/할인율, 판매중지(주문 이력이 있으면 삭제 대신 숨김), 이미지 매직넘버 검증.
- **보안**: helmet(CSP 포함), 로그인 실패 기반 rate limit, 계정 존재 여부 타이밍 노출 방지, 로그인 후 리다이렉트 검증, 본인 주문 외 404.
- **운영**: 버전 관리 마이그레이션(시작 시 자동, advisory lock), DB 포함 헬스체크(`/health`), 요청 ID·구조화 로그, 정상 종료.
- **화면**: 디자인 시스템(Pretendard, 펠트 그린) 적용, 전 화면 반응형, 관리자 대시보드(매출·단계별 현황·재고 부족).

## 검토한 대안
- Next.js 로 전환(SSR/SEO) → 기존 ADR-086 결정과 배포 구성을 바꿔야 해서 제외. 상품 SEO 가 중요해지면 재검토.
- JWT 를 httpOnly 쿠키로 이전 → CSRF 대책과 배포 도메인 구성이 함께 바뀌어야 해 이번 범위에서 제외(아래 '남은 과제').
- react-router v7 업그레이드(감사 경고) → 주요 버전 변경이라 제외. 해당 취약점(백슬래시 오픈 리다이렉트)은 리다이렉트 검증으로 차단, SSR 관련 항목은 SPA 라 해당 없음.

## 영향
- DB: 마이그레이션 v2 가 기존 테이블에 컬럼을 추가합니다(기존 데이터 보존). 
- API: 오류 응답 형식이 `{ error: "메시지", code, details? }` 로 바뀌었습니다. 체크아웃 요청에 `shipping` 이 필수가 되었습니다.
- 감수: 실제 PG 키·HTTPS·사업자 정보·약관 문안은 운영자가 설정하고 검토해야 합니다. 빌드·자동 테스트 통과가 업무 정확성을 보장하지는 않습니다.

## 남은 과제 (운영 규모가 커지면)
- 비밀번호 재설정(이메일 발송), 회원 탈퇴, 배송지 주소록
- 주문/배송 알림(카카오 알림톡·이메일)
- JWT → httpOnly 쿠키 세션, 관리자 2단계 인증
- 국내 PG(토스페이먼츠·포트원) 연동이 필요하면 `payments/` 에 어댑터 추가
- 상품 옵션(색상·사이즈), 리뷰, 쿠폰/적립금
