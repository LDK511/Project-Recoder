# ADR-010: 어떤 아키텍처로 구축할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**풀스택 (프론트 + 백엔드)** — Node.js/Express + React/Vue 등

근거(장점):
- 확장성 높음
- 실제 운영 환경과 유사
- 다중 사용자 지원

## 검토한 대안
- 프론트엔드 전용 (React/Vue + 로컬 스토리지) → 기기 간 데이터 공유 불가, 실제 운영 어려움 이유로 제외

## 영향
전체 프로젝트 구조 결정 · 감수: 초기 설정 복잡, 배포 필요
