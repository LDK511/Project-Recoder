# ADR-016: 백엔드 아키텍처를 어떻게 구성할까요?

- 상태: 승인됨
- 날짜: 2026-10-03
- 요청: 실제 운영 가능한 쇼핑몰 하나 만들어줘

## 결정
**Node.js + Express** — JavaScript 기반 경량 서버

근거(장점):
- 빠른 개발
- JavaScript 통일
- 풍부한 라이브러리

## 검토한 대안
- Python + Django (풀스택 프레임워크) → 학습곡선 가파름, 배포 복잡도 증가 이유로 제외
- Serverless (Firebase/AWS Lambda) (서버 관리 없는 클라우드) → 벤더 종속성, 콜드 스타트 지연 이유로 제외

## 영향
전체 개발 환경 및 배포 방식 결정 · 감수: CPU 집약적 작업 약함, 대규모 확장성 제한
