# ADR-021: 프론트엔드 프레임워크는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-09
- 요청: 실제 운영 가능한 쇼핑몰 만들어줘

## 결정
**React** — 컴포넌트 기반 UI 라이브러리

근거(장점):
- 생태계 풍부
- 성능 우수
- 커뮤니티 큼

## 검토한 대안
- Vue.js (점진적 프레임워크) → 생태계 상대적 작음 이유로 제외
- Vanilla JavaScript (프레임워크 없이 순수 JS) → 개발 속도 느림, 유지보수 어려움 이유로 제외

## 영향
개발 속도, 유지보수성, 성능 결정 · 감수: 학습곡선 가파름
