# ADR-088: 상품 이미지와 파일은 어디에 저장할까요?

- 상태: 승인됨
- 날짜: 2026-10-11
- 요청: 실제 운영 가능한 쇼핑몰을 만들어주세요.

## 결정
**AWS S3 (또는 호환 서비스)** — 클라우드 객체 스토리지

근거(장점):
- 높은 확장성
- CDN 연동 용이

## 검토한 대안
- 로컬 파일시스템 (서버 디스크에 직접 저장) → 확장성 제한, 백업 관리 필요 이유로 제외
- Cloudinary 등 이미지 CDN (이미지 최적화 및 CDN 제공) → 제3자 서비스 의존 이유로 제외

## 영향
파일 관리 방식과 운영 비용 결정 · 감수: 월별 비용 발생
