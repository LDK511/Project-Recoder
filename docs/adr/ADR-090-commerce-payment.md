# ADR-090: 결제는 어떻게 시작할까요?

- 상태: 승인됨
- 날짜: 2026-10-11
- 요청: 실제 운영 가능한 쇼핑몰을 만들어주세요.

## 결정
**키 없이 모의 결제로 바로 실행** — 첫 로컬 배포를 결제를 끈 데모로 띄웁니다. 모의 결제 서버가 함께 뜨고 주문은 '결제 완료(테스트)' 가 됩니다.

근거(장점):
- Stripe 계정 없이 바로 써 볼 수 있음

## 검토한 대안
- Stripe 테스트 키를 넣고 실행 (첫 로컬 배포 때 Stripe 비밀 키·웹훅 서명 키를 입력받아 실제 Stripe 테스트 모드로 연결합니다.) → Stripe 계정과 키가 필요함 이유로 제외

## 영향
첫 로컬 Docker 배포의 결제 모드를 정합니다. 배포 화면에서 언제든 바꿀 수 있습니다. · 감수: 실제 카드 결제는 일어나지 않음, 운영 전에 실제 키로 바꿔야 함
