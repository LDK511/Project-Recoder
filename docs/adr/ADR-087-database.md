# ADR-087: 데이터베이스는 어떤 것을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-11
- 요청: 실제 운영 가능한 쇼핑몰을 만들어주세요.

## 결정
**PostgreSQL** — 관계형 DB, 강력한 쿼리, 트랜잭션 안정성

근거(장점):
- ACID 보장
- 복잡한 쿼리 지원

## 검토한 대안
- MongoDB (문서형 NoSQL, 유연한 스키마, 수평 확장 용이) → 트랜잭션 복잡함 이유로 제외
- SQLite (경량 파일 기반 DB, 설정 최소화) → 동시성 제한, 대규모 확장 어려움 이유로 제외

## 영향
데이터 저장 구조, 쿼리 방식, 확장성 결정 · 감수: 스키마 설계 필요
