# ADR-011: 데이터베이스는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**PostgreSQL** — 관계형 DB, 프로덕션 표준

근거(장점):
- 안정성 높음
- 복잡한 쿼리 지원
- 확장성 우수

## 검토한 대안
- MongoDB (NoSQL, 유연한 스키마) → 트랜잭션 제한, 메모리 사용량 많음 이유로 제외
- SQLite (경량 파일 기반 DB) → 동시성 제한, 대규모 확장 어려움 이유로 제외

## 영향
데이터 관리 및 성능 · 감수: 설정 복잡도, 리소스 소비
