# ADR-009: 결제 시스템을 어떻게 구현할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 실제 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**로컬 결제 처리** — 자체 결제 로직 구현

근거(장점):
- 완전한 커스터마이징

## 검토한 대안
- Stripe API 연동 (외부 결제 게이트웨이) → 수수료 발생, API 키 관리 필요 이유로 제외
- Mock 결제 (테스트용) (실제 결제 없이 시뮬레이션) → 실제 운영 불가, 프로덕션 미지원 이유로 제외

## 영향
결제 기능 및 보안 정책 결정 · 감수: PCI 규정 준수 어려움, 보안 위험
