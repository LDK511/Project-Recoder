# ADR-085: 백엔드 프레임워크는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-11
- 요청: 실제 운영 가능한 쇼핑몰을 만들어주세요.

## 결정
**Node.js + Express** — 경량 HTTP 서버, JavaScript 풀스택 개발 가능

근거(장점):
- JavaScript 통일
- 빠른 개발
- Stripe 라이브러리 풍부

## 검토한 대안
- Python + Django (풀 기능 프레임워크, 강력한 ORM과 관리자 패널) → 학습곡선 가파름 이유로 제외
- Python + FastAPI (현대적 비동기 프레임워크, 자동 API 문서화) → 생태계 상대적으로 작음 이유로 제외

## 영향
전체 서버 아키텍처와 개발 언어 결정 · 감수: CPU 집약적 작업 약함
