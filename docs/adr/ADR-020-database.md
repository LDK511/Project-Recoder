# ADR-020: 데이터베이스는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-09
- 요청: 실제 운영 가능한 쇼핑몰 만들어줘

## 결정
**PostgreSQL** — 관계형 데이터베이스, 오픈소스

근거(장점):
- 안정성 높음
- 복잡한 쿼리 지원
- 무료

## 검토한 대안
- MongoDB (NoSQL 문서 데이터베이스) → 트랜잭션 제한, 저장소 용량 큼 이유로 제외
- SQLite (경량 파일 기반 데이터베이스) → 동시성 약함, 대규모 확장 어려움 이유로 제외

## 영향
데이터 관리 방식, 확장성, 운영 복잡도 결정 · 감수: 셋업 복잡도
