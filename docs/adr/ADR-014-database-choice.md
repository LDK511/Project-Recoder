# ADR-014: 데이터베이스는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**MongoDB (NoSQL)** — 유연한 스키마, JSON 기반

근거(장점):
- 개발 속도 빠름
- 확장성 좋음
- Node.js와 호환성 우수

## 검토한 대안
- PostgreSQL (SQL) (관계형 데이터베이스, 안정성 중심) → 스키마 설계 필수, 초기 설정 복잡 이유로 제외
- Firebase (BaaS) (구글 관리형 서비스) → 비용 증가 가능, 벤더 종속성 이유로 제외

## 영향
데이터 관리 방식과 운영 복잡도 결정 · 감수: 트랜잭션 복잡, 저장소 용량 더 필요
