# ADR-018: 프론트엔드 프레임워크는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-10-03
- 요청: 실제 운영 가능한 쇼핑몰 하나 만들어줘

## 결정
**React** — 컴포넌트 기반 라이브러리

근거(장점):
- 생태계 풍부
- 성능 우수
- 커뮤니티 활발

## 검토한 대안
- Vue.js (점진적 프레임워크) → 생태계 상대적 소규모, 채용 시장 제한 이유로 제외
- Vanilla JavaScript (프레임워크 없음) → 개발 시간 증가, 유지보수 어려움 이유로 제외

## 영향
UI 개발 방식 및 개발 생산성 결정 · 감수: 학습곡선, 번들 크기 증가
