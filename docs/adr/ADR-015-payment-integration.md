# ADR-015: 결제 시스템을 어떻게 연동할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**아임포트 (국내)** — 한국 결제 통합 서비스

근거(장점):
- 국내 카드/계좌 지원
- 낮은 수수료
- 한글 문서

## 검토한 대안
- Stripe (국제 결제 플랫폼) → 수수료 높음, 국내 카드 제한 이유로 제외
- 모의 결제 (테스트용) (실제 결제 없이 테스트) → 실제 운영 불가, 나중에 교체 필요 이유로 제외

## 영향
결제 기능 구현 방식과 운영 비용 결정 · 감수: 국제 결제 제한, 소규모 업체
