# ADR-008: 데이터베이스는 무엇을 사용할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 실제 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**PostgreSQL** — 관계형 데이터베이스

근거(장점):
- 안정성과 신뢰성 높음
- 복잡한 쿼리 지원
- 운영 환경 표준

## 검토한 대안
- MongoDB (NoSQL 문서 데이터베이스) → 트랜잭션 복잡, 쇼핑몰 데이터 구조에 덜 적합 이유로 제외
- SQLite (경량 파일 기반 DB) → 동시성 제한, 프로덕션 부적합 이유로 제외

## 영향
데이터 저장소 및 쿼리 방식 결정 · 감수: 설정 복잡, 로컬 개발 환경 구성 필요
