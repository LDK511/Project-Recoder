# ADR-013: 백엔드 아키텍처를 어떻게 구성할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**Node.js + Express (풀스택)** — JavaScript 기반 통합 개발

근거(장점):
- 프론트/백 언어 통일
- 빠른 개발
- 풍부한 라이브러리

## 검토한 대안
- 정적 HTML/CSS/JS (프론트만) (서버 없이 클라이언트 중심) → 실시간 기능 제한, 결제 연동 어려움 이유로 제외
- Python + Django (안정적인 웹 프레임워크) → 학습곡선 가파름, 배포 복잡도 증가 이유로 제외

## 영향
전체 기술 스택과 개발 속도 결정 · 감수: 성능 최적화 필요, 대규모 확장성 제한
