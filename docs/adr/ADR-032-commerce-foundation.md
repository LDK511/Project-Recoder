# ADR-032: 운영형 쇼핑몰의 시작 방식을 선택하세요

- 상태: 승인됨
- 날짜: 2026-10-10
- 요청: 실제 운영 가능한 형태의 쇼핑몰을 하나 만들어주세요.

## 결정
**AI 자유 생성** — 요청에 따라 새 코드를 생성합니다. 생성 후 별도 업무·보안 검증이 필요합니다.

근거(장점):
- 자유로운 구성

## 검토한 대안
- 검증된 쇼핑몰 기반 (React·Express·PostgreSQL·Stripe 구성. 가입, 상품, 장바구니, 주문, 재고, 서명 웹훅, 관리자 화면을 포함합니다.) → 이 기술 구성을 사용합니다, 실제 결제사 키·HTTPS·상품·사업 정책은 운영자가 설정합니다 이유로 제외

## 영향
기반 사용 여부와 고정 기술 구성을 설계 기록에 남깁니다. 실제 결제사 연동은 계정 설정 후 검증해야 합니다. · 감수: 빌드 통과만으로 업무 정확성을 보장하지 않습니다
