# ADR-007: 전체 아키텍처를 어떻게 구성할까요?

- 상태: 승인됨
- 날짜: 2026-09-27
- 요청: 실제 운영 가능한 쇼핑몰 사이트 만들어줘

## 결정
**풀스택 (Node.js + React/Vue)** — 백엔드 서버 + 프론트엔드 분리

근거(장점):
- 실제 운영 환경과 동일한 구조
- 확장성과 유지보수성 우수
- 데이터베이스 연동 용이

## 검토한 대안
- 정적 사이트 (HTML/CSS/JS) (프론트엔드만 구현, 로컬 스토리지 사용) → 실제 운영 불가능, 다중 기기 동기화 불가 이유로 제외
- Next.js (풀스택 프레임워크) (API 라우트 + SSR 통합) → Node.js 런타임 필수, 학습곡선 이유로 제외

## 영향
프로젝트 전체 구조 결정 · 감수: 초기 설정 복잡, 배포 환경 필요
