# ADR-019: 백엔드 아키텍처를 어떻게 구성할까요?

- 상태: 승인됨
- 날짜: 2026-10-09
- 요청: 실제 운영 가능한 쇼핑몰 만들어줘

## 결정
**Node.js + Express** — JavaScript 기반 경량 서버 프레임워크

근거(장점):
- JavaScript 통일
- 빠른 개발
- 풍부한 라이브러리

## 검토한 대안
- Python + Flask (Python 기반 마이크로 프레임워크) → 별도 언어 학습, 배포 복잡도 이유로 제외
- Serverless (AWS Lambda 등) (서버 관리 없는 클라우드 기반) → 초기 비용, 벤더 종속성 이유로 제외

## 영향
개발 언어, 배포 방식, 운영 난이도 결정 · 감수: CPU 집약적 작업 약함
